# Карта источников

Проверено 13 октября 2026 года. «Прочитан» ниже означает доступный текст указанного раздела, а не всю документацию продукта. Доступность в другой сети может отличаться. Номера сборок платформы, поддерживаемых проектом, не сертифицированы. Повторная содержательная проверка и изменения отмечены в [аудите перед публикацией](publication-review.md).

В инструкциях различаются **механизм платформы**, **требование/рекомендация официального стандарта** и **собственное инженерное решение**. Наличие ссылки не означает, что статья доказывает корректность нашего patch или ускорение.

Старые статусы «не исполнялось» в таблице описывают первый аудит. Более поздние фактические исполнения — в [итоговом отчёте](final-validation.md) и [платформенном протоколе](../evals/platform/README.md); документация 8.3.27 не означает испытание именно этой версии.

## Доступность руководств и книг

- [Русскоязычные стандарты ИТС](https://its.1c.ru/db/v8std): индекс вернул `403 Forbidden`. Прямая статья стандарта 783 открылась и прочитана (см. таблицу); прямой текст стандарта обработки исключений 499 не загрузился. Нельзя обобщать доступность одной страницы на весь раздел. [Английский индекс стандартов](https://kb.1ci.com/1C_Enterprise_Platform/Guides/Developer_Guides/1C_Enterprise_Development_Standards/) открылся, но в выгрузке только заголовок; содержательные страницы проверялись отдельно. Равенство русской и английской редакций не установлено.
- [Корень Developer Guide 8.3.23](https://kb.1ci.com/1C_Enterprise_Platform/Guides/Developer_Guides/1C_Enterprise_8.3.23_Developer_Guide/) перенаправил на страницу поддержки. Это не прочитанное руководство. Правила ограниченной первой версии опираются на доступные официальные пояснения выше; сертификация по полной документации конкретной сборки остаётся невыполненной.
- [Developer Guide 8.3.27](https://1c-dn.com/library/tutorials/1c_enterprise_developer_guide_8_3_27/): большая официальная HTML-страница получена обычным HTTP-запросом без авторизации и обхода доступа. Прочитаны только выбранные разделы таблицы и описание параметров процедуры в §4.6.3. Веб-инструмент выдавал ограничение размера; загрузка HTML не равнозначна чтению всего руководства. Синтакс-помощник и выполнение на 8.3.27 этим не заменяются.
- [Е. Ю. Хрусталева, «Язык запросов „1С:Предприятия 8“»](https://v8.1c.ru/metod/books/193205.htm): прочитаны описание и оглавление каталога, **полный текст не изучен**. Каталог указывает третье стереотипное издание 2025 года и платформу примеров 8.3.3.687; свежая дата не означает переписывание механизмов под текущую платформу. Книга — ориентир для дальнейшего изучения, а не доказательство наших технических правил.
- [М. Г. Радченко, Е. Ю. Хрусталева, «1С:Предприятие 8.3. Практическое пособие разработчика»](https://buh.ru/books/161314.html): доступна каталожная карточка третьего издания. **Полный текст не изучен**, проект книги и главы не копировались.
- БСП: в примерах нет её вызовов. При применении к проекту API требуется сверять с документацией **используемой версии** библиотеки; эта работа заранее не выполнена.

## Подключение в AI-инструменте

[OpenAI — Build skills](https://learn.chatgpt.com/docs/build-skills), разделы How ChatGPT and Codex use skills, Where Codex loads local skills, Create a skill: текст открыт и прочитан 13.10.2026. Подтверждены `SKILL.md`, поля `name`/`description`, локальный каталог `.agents/skills` для репозитория, вызов через `$` или `/skills` в CLI/IDE и повторное обнаружение изменений. Старый URL `developers.openai.com/codex/skills/` перенаправляет сюда.

README описывает только этот локальный способ для Codex CLI/IDE. Совместимость установки с другими инструментами, магазином плагинов и всеми версиями Codex не проверена. Прямое чтение `SKILL.md` другим агентом возможно как передача инструкций, но не считается проверкой его автоматического обнаружения.
