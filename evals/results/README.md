# Ответы первого ограниченного прогона

Этот раздел сохраняет оценку первого прогона, уточнённую аудитом D1. Отдельный повтор после изменения debug: [протокол и оценка](../review-d1.md), [ответ](D1-review.md). Он не заменяет исходный D1 и не повторяет остальные восемь заданий.

13.10.2026 выполнены девять заданий встроенными оценщиками Codex по workflow `skill-creator`. Созданы три отдельных оценщика с `fork_turns=none`, без передачи авторской истории и без переопределения модели. Каждый последовательно решил три задания одного скилла. Между заданиями контекст **не сбрасывался**, поэтому девять ответов не являются девятью полностью независимыми измерениями. Точный идентификатор модели, seed и полный системный контекст не зафиксированы; повторяемость ограничена.

Оценщикам явно указаны скилл и разрешённые исходники; автоматический выбор по description не тестировался. Эталоны и авторские критерии проблемных сценариев не передавались. В последующих заданиях на корректный код `after` был входом по смыслу сценария. Входы: [inputs.md](../inputs.md).

Ответы сохранены без редактирования существенного текста. Абсолютные пути рабочей машины, если встречались, заменены на `{{REPO_ROOT}}`/`{{WORK_ROOT}}`; это обезличивание путей, не изменение решения. Предлагаемый оценщиком код может отличаться от опубликованного примера. Сохранён ответ, а не полный журнал инструментов; указанные оценщиком дополнительные текстовые/модельные проверки нужно отличать от авторского воспроизводимого набора `scripts/check_examples.py`.
