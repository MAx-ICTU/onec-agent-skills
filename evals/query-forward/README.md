# Независимые контексты Q2–Q4

13.10.2026 выполнены три новых прогона и повтор Q4 после уточнения справочника. Каждый запуск — отдельный Codex-субагент с `fork_turns: none`, без передачи истории. Ему разрешались только свой входной пакет, собственные артефакты и стандартная библиотека Python. `after`, expected-поля, оценка автора, прежние ответы, другие агенты и Интернет не передавались. Агент явно читал скилл; автоматический выбор скилла этим не проверен.

Входы находятся в `Q*/input`: постановка, исходник и данные. Чтобы восстановить полный пакет, скопируйте туда папку соответствующей редакции из `revisions/` под именем `skill`. Сохранённые SHA256 в `input-hashes.json` проверяют именно исходный полный пакет. Общая копия каждой редакции устраняет дублирование одинаковых материалов между кейсами.

Инструмент, доступные сведения о модели, ограничения и исходные хеши артефактов: [metadata.json](metadata.json). API запуска не раскрыл точный идентификатор модели, reasoning и LLM seed; они не восстановлены по догадке. Модель и настройки наследовались без переопределений. Общие системные инструкции сервиса не изолировались. Независимость относится к истории и материалам задачи, а не к отдельной модели или исследователю.

Полные ответы, предлагаемый код и исполненные скрипты сохранены без редактирования. В `checks.txt` заменены только локальные пути на `{{RUN_ROOT}}` и `{{PYTHON}}`, нормализованы UTF-8 и переводы строк. Исходные хеши позволяют отличить эту обработку от изменения ответа. Данные и скрипты сохранены байт в байт. Журналы фиксируют выполненные модели, а не запуск 1С. Платформенные проверки автор выполнил позднее и описал [отдельно](../platform/README.md).

## Редакции и причина повтора

Первым трём агентам переданы [initial/SKILL.md](revisions/initial/SKILL.md) и [initial/reference](revisions/initial/references/query-pitfalls.md). `SKILL.md` имеет SHA256 `6dfc9c7474c43e5fb0a755dee0536964c6ae394279c643df0c3a7f18bb03df81`, reference — `4e61eb11b0efdfee68a0e3f5a690fde27fa13cb4026e4b00cb6e3e4f0be1213c`.

Платформа выявила ошибку **старого авторского примера Q4**, а не первоначального ответа агента: обратное сопоставление по строковому ключу теряло цену при различии регистра/завершающих пробелов. Неудачный код и результат сохранены в [платформенном протоколе](../platform/README.md). Пример исправлен узко: соединение выполняется в запросе, результат привязывается к числовому идентификатору. В reference добавлено правило сравнения строк с официальным источником и отдельной инженерной рекомендацией. Сам `SKILL.md` не менялся.

Повтор получил только [string-comparison/SKILL.md](revisions/string-comparison/SKILL.md), [новый reference](revisions/string-comparison/references/query-pitfalls.md) и тот же исходный Q4 без прежнего ответа, исправления автора или описания сбоя. Новый reference совпадает с установленным скиллом; точный SHA256 есть в metadata. Оба ответа Q4 сохранены. Неудачного ответа Q4-агента не было; неудачный **платформенный прогон примера** не переименован в провал агента.

Это ограниченная учебная оценка. Нет слепого внешнего рецензента, сравнения с агентом без скилла, оценки вероятности успеха или испытания всех допустимых данных. Старые результаты R/D/Q1/Q5/Q6 остаются в [первом наборе](../results/README.md), включая первоначальный partial D1 и его отдельный повтор.
